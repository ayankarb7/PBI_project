## Модель данных

Построена по схеме **«звезда»**: справочники клиентов, дат, регионов и
тарифов соединены с таблицами фактов (звонки, SMS, интернет-трафик,
биллинг) через ключевые поля. Настроена таблица дат, лишние технические
ID убраны на этапе Transform data, реализованы основные DAX-меры для
анализа выручки, ARPU, активности клиентов, трафика, звонков, SMS,
оттока и выполнения плана (см. `05_data_model_star_schema.png`).

## Страницы дашборда

Каждая страница рассчитана на свою аудиторию и отвечает на её главные
вопросы.

### 1. Executive Summary (`01_executive_summary.png`)
Для руководителя — общая картина по бизнесу. Ключевые показатели: общая
выручка, ARPU, количество активных клиентов, динамика по месяцам,
уровень оттока, сравнение факта с планом, ежедневная динамика выручки и
её распределение по сегментам. Позволяет за секунды понять, растёт ли
бизнес и есть ли риски по оттоку.

### 2. Customer Analytics (`02_customer_analytics.png`)
Для маркетинга — кто основные клиенты и за счёт кого формируется
выручка: список самых прибыльных клиентов, ABC-анализ, зависимость
возраста от ARPU, распределение выручки по городам, регионам и
сегментам. Помогает понять, на удержании каких групп клиентов
сосредоточиться (клиенты группы А требуют особого внимания).

### 3. Operations (`03_operations.png`)
Для операционного отдела — когда возникает наибольшая нагрузка и как
распределяются звонки, SMS и интернет-трафик: динамика по дням, тепловая
карта нагрузки по дням недели и часам, стоимость по типам звонков и
расходы на роуминг. Помогает планировать технические работы на время
низкой нагрузки и выявлять часы пик.

### 4. Tariff Performance (`04_tariff_performance.png`)
Для продуктовой команды — какие тарифы работают лучше всего: выручка по
тарифам, ARPU по тарифам и сегментам, сравнение абонентской платы с
ARPU, рейтинг тарифов и их ABC-группа. Помогает выявлять тарифы с низкой
абонплатой, но высоким ARPU, и наоборот.

### Адаптивная вёрстка (`06_mobile_layout.png`)
Настроен мобильный layout для Executive Summary — ключевые карточки и
графики адаптированы под просмотр со смартфона.

## Что важно для бизнеса

- Большая часть выручки приходит от небольшого числа клиентов и тарифов
  — стоит уделять особое внимание клиентам группы А и самым доходным
  тарифам.
- Важно следить за оттоком: даже при хорошей текущей выручке высокий
  отток создаёт риски в будущем.
- Разные регионы и сегменты по-разному влияют на выручку — рекламу и
  продажи стоит планировать с учётом этих различий.
- Дашборд также полезен операционной команде: показывает, когда нагрузка
  большая, а когда маленькая, что помогает распределять сотрудников и
  планировать технические работы.

## Что можно доработать, если бы было больше времени

1. Глубже изучить причины оттока клиентов — связь с тарифом, регионом,
   возрастом и активностью.
2. Сделать прогноз выручки и нагрузки на ближайшие месяцы.
3. Добавить больше страниц с детальной информацией (отдельно по тарифам
   и регионам).
4. Улучшить внешний вид, добавить больше подсказок для пользователей.
5. Создать отдельную страницу с рекомендациями: какие тарифы продвигать,
   каких клиентов удерживать, где риск снижения выручки.
